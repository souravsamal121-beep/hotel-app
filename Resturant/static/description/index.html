🍽️ Restaurant Website Theme

Version: 17.0.1.0.0 | Category: Website/Theme

⚠️ Important Note About Images:
This module includes all the original image references from your website. Images are loaded dynamically - if an image with the matching name exists in your Odoo database, it will be displayed. If not, that section will still work but without the image. No image names have been changed from your original code.

1. Hero Carousel
Full-screen carousel with fade transitions, featuring food imagery backgrounds
2. Delicious Food Header
Main hero section with "Delicious Food" heading and Order Now button

4. Our Special Section
Four category cards: Breakfast, Main Dishes, Dessert, and Special

6. Our Chefs Section

Dynamic product snippet for showcasing menu items
8. Experience Parallax
Parallax scrolling section with "EXPERIENCE OF REAL RECIPES TASTE"
9. Final Parallax Section
Fixed background parallax section for visual impact

🖼️ Image Handling

The module preserves all original image paths. When you install it:

  • If images exist in your database with matching names → they display automatically
  • If images don't exist → sections render without images (no broken links)
  • All original image filenames and paths are preserved exactly as provided

🚀 Installation

  1. Copy the Resturant folder to your Odoo addons/ directory
  2. Update app list in Odoo (Settings → Activate Developer Mode → Update Apps List)
  3. Search for "Restaurant Website Theme" and install
  4. The snippets will be available in your website builder
